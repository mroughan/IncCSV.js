Use IncCSV.js from R Shiny

Shiny can load the browser bundle, parse INC files in the browser, and send the parsed object to the R server with Shiny.setInputValue.

Build

Build the global browser bundle before running the example app.

npm install
npm run build

Load

The Shiny UI loads the bundle and a small app-specific bridge.

tags$script(src = "inccsv.browser.js")
tags$script(src = "inc-shiny.js")

Send

The browser sends parsed INC data to the Shiny server.

const file = window.IncCSV.parseInc(text);
Shiny.setInputValue("inc_file", file, {
  priority: "event"
});

Example App

A complete Shiny example is included in examples/shiny/. Run it from that directory: 

R -e 'shiny::runApp(".")'
