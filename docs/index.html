INC files in JavaScript

IncCSV.js reads and writes CSV data with a small metadata block, using the language-neutral INC specification as its contract.

Parse

Use parseInc(text) in browsers or Node.js. Plain CSV is accepted and returns empty metadata. 

import { parseInc } from "inccsv";

const file = parseInc(text);
console.log(file.metadata);
console.log(file.rows);

Write

Use writeInc to serialize metadata, columns, and rows with deterministic metadata ordering. 

import { writeInc } from "inccsv";

const text = writeInc({
  metadata,
  columns,
  rows,
});

Validate

Read mini-schema text and check metadata requirements before a file enters a workflow. 

const schema = readSchemaFromText(schemaText);
const result = validateSchema(file, schema);

Bundle

Build a browser global for Shiny and other script-tag workflows. 

npm run build

window.IncCSV.parseInc(text);
